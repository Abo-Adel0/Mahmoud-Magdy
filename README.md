# Mahmoud Magdy — Premium Personal Website

React + Vite one-page profile site for Coach Mahmoud Magdy, Founder & CEO of Falcons Organization.

## Included
- Premium dark/light theme toggle in the navbar
- Active navbar underline follows the current section
- Right-side section navigation dots with active glow + labels
- Mouse-following ambient glow
- Hero portrait parallax that subtly follows the mouse
- Transparent falcon mark behind the coach
- Fast animated trading candlesticks + market arrows
- Scroll-triggered fade/slide reveals
- Updated impact counters: 5+ years, 12,000+ active members, 12,000+ students trained, 18 countries, 95% satisfaction
- Refreshed Falcons website screenshot preview cropped to website content only
- Responsive mobile layout with horizontal overflow protection
- WhatsApp and Instagram links

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.


## Final design pass
- Static hero finance wallpaper in `public/images/hero-market-bg.png`
- Portrait is fixed and enlarged; legacy moving arrow/falcon overlays are disabled
- Theme toggle is a proper navbar switch
